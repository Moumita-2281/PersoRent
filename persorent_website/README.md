# PersoRent Website Prototype

This is a front-end prototype for a peer-to-peer vehicle rental marketplace.

## What is included

- Landing page
- Vehicle search and filter
- Demo listings for bikes, scooters and cars
- Owner vehicle listing form
- Login modal
- KYC verification demo modal
- Booking and security deposit modal
- Damage photo proof demo modal
- Dashboard mock-up for KYC, bookings, deposits and photos
- Fully responsive design

## How to run

Open `index.html` in any browser.

No backend is included yet. The current listings are stored in browser memory only, so they reset after refresh.

## Recommended backend later

- Frontend: Next.js or React
- Backend: Node.js + Express / NestJS
- Database: PostgreSQL
- File storage: AWS S3 or Cloudinary
- Payments: Razorpay / Cashfree
- KYC: compliant Aadhaar offline e-KYC and driving licence verification provider
- Admin dashboard: approve users, listings and disputes

## Important launch warning

Before launching in India, verify legal compliance for vehicle rental, commercial registration, permits, insurance, PUC, deposits, dispute handling, data privacy and KYC consent. Do not allow illegal private-vehicle renting.
